# V1 reported results

These are full-precision transcriptions of selected fields from the completed
server output supplied by the project owner in this session. They are not
independently downloaded server artifacts and do not replace the originals.

- `reported_holdout_metrics.csv`: native-resolution image-macro metrics from
  the reported `holdout/metrics/final_metrics.csv`; blank cells are undefined.
- `reported_summary.json`: reported completion/checkpoint metadata, selected CV
  summaries and the last known V2 status. Fold SD is descriptive, not a CI.

The original holdout checkpoint hash was reported in `evaluation_status.json`.
The selected epoch and validation metrics came from the owner's checkpoint
report. No datasets, per-image private records, checkpoints or predictions are
included. Raw artifacts remain on the server under the independent V1 folders.
